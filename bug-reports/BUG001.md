# BUG001 – All Product Images Display a Dog Instead of Correct Images

**Project:** SauceDemo  
**Module:** Products / Inventory  
**Bug Type:** UI / Functional Defect  
**Environment:** Windows desktop, Google Chrome
**Test Account:** problem_user  
**Status:** New  
**Severity:** Medium  
**Priority:** Medium  

## 1. Bug Description

All product images displayed on the inventory page show a dog instead of the correct product images associated with their product names.

## 2. Preconditions

- User must have access to the SauceDemo website.
- User must log in using the problem_user test account.

## 3. Steps to Reproduce

1. Open https://www.saucedemo.com/.
2. Enter username: problem_user.
3. Enter password: secret_sauce.
4. Click the Login button.
5. Navigate to the inventory/products page.
6. Observe the product images.

## 4. Expected Result

Each product should display its correct image corresponding to its product name.

## 5. Actual Result

All product images display a dog instead of the correct product images. Therefore, the images do not match the displayed product names.

## 6. Severity and Priority

- Severity: Medium – Incorrect product images negatively affect the user experience and product identification.
- Priority: Medium – The issue should be fixed to ensure correct product presentation.

## 7. Test Result

**Status:** Defect identified and documented.
